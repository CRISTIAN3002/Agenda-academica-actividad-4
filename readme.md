# Agenda Académica 
Aplicación web interactiva del lado del cliente desarrollada con JavaScript ES6+ para la gestión de tareas universitarias y proyectos académicos.
## Características Principales 
* **CRUD Completo:** Permite registrar, visualizar, editar y eliminar actividades.
* **Manipulación del DOM:** La interfaz se actualiza dinámicamente sin recargar la página mediante el uso de `innerHTML` y creación de elementos.
* **Persistencia Local:** Los datos se conservan entre sesiones utilizando `localStorage`.
* **Validación de Datos:** El formulario verifica que todos los campos requeridos estén llenos antes de procesar la información.
* **JavaScript Moderno:** Implementación de ES6+ incluyendo `let/const`, Arrow Functions (`=>`), Template Literals (`` ` ``) y métodos de arreglos (`.filter()`, `.map()`, `.find()`, `.forEach()`).
* **Funciones Adicionales:** Incluye un sistema de filtrado de tareas por categoría (Materia) y un contador dinámico en tiempo real del total de actividades en pantalla.
## Tecnologías Utilizadas
* HTML5 (Estructura semántica)
* CSS3 (Diseño responsivo y variables de color)
* JavaScript ES6+ (Lógica de negocio y eventos)
